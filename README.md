# Dream Catalogue v0.2.8.2 — WEBGL Brush-up

Direct brush-up of the v0.2.8 WEBGL codebase. The application structure, UI, controls, rendering architecture, REVEAL logic and mode engines are preserved.

Changes only:
- HALO: unchanged from v0.2.8.
- PRISM: modest lift to refraction/diffraction/caustic/ray visibility; no new geometry or engine replacement.
- SMOKE: same volumetric engine, shifted from gray smoke toward luminous off-white / cool-white vapor; darker pockets reduced and colored rays are less overlay-like.
- VEIL: same membrane engine, slightly stronger membrane visibility, pearlescence, arcs and milky transmission.
- Still p5.js WEBGL / GLSL, static single-pass per mode.

PWA files and icons are included.
